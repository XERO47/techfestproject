# Weather Alert System
In this repository we have integrated Uagents library with stream-lit, fast-api to make autonomous Agents to generate alert for weather conditions via Email, and streamlit Frontend.


**Note**: Enter your email address in the input bar and press "Enter".

## Step-1: GET API KEY FROM Weatherapi.com(Optional)
Use the API key Already provided in the repository.
Get a API key from Weatherapi.com(Optional)
And set the api key in .env file(Optional)

## Step-2: Git clone the repository.
Open a terminal in root directory of the repository & Enter the following commands
```bash
poetry install
```
```bash
cd ./src
```
```bash
poetry shell
```
```bash
python main.py
```
### Your Streamlit application should start shortly.
